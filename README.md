# Automated PRD-to-API Specification Generator

## Overview

This project demonstrates a recursive AI workflow built with Google AI Studio (Gemini).

The workflow converts a simple product idea into structured software engineering artifacts using prompt chaining and structured JSON outputs.

## Workflow

1. Product Idea
2. Product Requirements Document (PRD)
3. Database Schema
4. Backend Data Models
5. REST API Specification
6. Validation Report

Each stage uses the output of the previous stage, demonstrating recursive prompting.
